# The autocorrect list this firmware is built with: what the keyboard
# replaces as it is typed until a profile with its own list is saved.
#
# One input per line, in QMK's form (typo -> correction):
#
#   :teh: -> the                  the whole word "teh"
#   :nu -> un                     "nu" at the start of a word
#   mnet: -> ment                 "mnet" at the end of a word
#   tihng -> thing                "tihng" anywhere in a word
#   :pnumber: -> +31 6 1234 5678  text of up to 128 bytes, on one line
#   :sig: => 12                   plays macro slot 12, for the whole word
#
# Several inputs may name one replacement; each names only one. An input
# is letters and digits, with apostrophes only between them, and is
# matched whatever its case. After a change, regenerate authored_autocorrect_list.h:
#
#   python3 tools/autocorrect/build.py --write-authored keyboards/bastardkb/charybdis/4x6/keymaps/noah
#
# The list ships empty.
