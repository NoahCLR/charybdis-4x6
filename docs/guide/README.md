# Firmware guide

What the firmware on your Charybdis does, and how to write its defaults in C.
To change the keyboard, use Charybdis Ark: its
[guide](https://github.com/NoahCLR/charybdis-ark/tree/dev/docs/guide) walks
through every screen. These pages say what the keyboard does with what you
set there.

1. [Installing and recovering](installing.md): flashing a release, what an
   update does to your profile, and getting back to a working keyboard.
2. [What keys can do](keys.md): tap, hold and long hold, tap counts, layer
   keys, combos and custom keys.
3. [Pointing modes](pointing.md): the 32 slots, scrolling and directional
   modes, the pointer layer and sniping.
4. [Lighting](lighting.md): the stages, layer colours and feedback.
5. [Saving and the two halves](saving.md): edits, Save, the edit modes, and
   how the halves stay the same.
6. [Macros and host layouts](macros.md): playback, your computer's keyboard
   layout and Unicode entry.
7. [Authoring in C](authoring.md): the profile files, `config.h`, adding a
   pointing mode and building the pair.
8. [Hook overrides](hooks.md): adding code of your own without losing the
   runtime.
