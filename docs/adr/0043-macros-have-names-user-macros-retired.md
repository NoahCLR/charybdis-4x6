# Macros have names; user macros are retired

Cited as D-F43. Was D-L25.

The 16 user macros were retired and the macros the profile holds can
be named instead, so there is one macro system and a client can edit all of
it. Names live in the settings domain and travel with every save, to the
other half and into backups. The user-macro runtime and `HARDCODED_MACROS` are
gone, and settings readback streams from the effective settings cache instead
of a second copy, saving RAM.
