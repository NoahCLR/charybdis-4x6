# Directional modes can read eight directions

Cited as D-F42. Was D-L24.

A directional mode can read the four diagonals as well as the four straight
directions, each with its own shortcut; a diagonal without one sends the
nearer straight direction, both neighbours or nothing, as the mode chooses.
It used bytes a directional record left zero, so the domain version did not
change for it. D-F45 replaced how a direction is chosen. Layout:
[`pd-mode-domain-v1.md`](../spec/pd-mode-domain-v1.md).
