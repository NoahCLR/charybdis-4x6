# Triage labels

The skills' five triage roles (`needs-triage`, `needs-info`,
`ready-for-agent`, `ready-for-human`, `wontfix`) are not label strings here.
They are values of a task's `status` and `kind` frontmatter fields in Noah's
notes vault (see `issue-tracker.md` for where it is). The vault's
`_agents/tracker.md`, "Triage roles", maps each role to its field and value;
apply that mapping wherever a skill names a role.
